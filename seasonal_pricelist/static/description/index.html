Seasonal Pricelist based on Delivery Date

1. Create Seasonal Pricelist

Create a pricelist named Seasonal Pricelist with valid start and end dates.

2. Create Sales Order

Create a Sales Order, add the required products, and proceed to the order screen.

3. Enable Delivery-based Pricing

Enable the option and choose a delivery date/time. The Seasonal Pricelist is auto-applied and the Update Prices button appears.

4. Update and View Prices

After clicking Update Prices, the system recalculates and applies the correct prices.
